## 1. 功能概述

### 1.1 目标

在 **本机客户端** 提供可配置的噪声抑制（Noise Suppression, NS），满足：

1. **多模型可选**：用户可在 **N 个开源、可本地运行** 的降噪模型中挑选（含浏览器内置能力作为一档；正式目录含 DeepFilterNet）。
2. **实时生效**：开关、换模型、改强度在 **当前语音会话中即时应用**，不退出频道、不重建 PeerConnection（允许重建本地音频处理链 / replaceTrack）。
3. **对自己（上行）**：对自己麦克风采集流降噪后再编码上行，让同频道他人听到更干净的声音。
4. **对他人（下行，本地）**：在语音参与者 **右键菜单 / 卡片菜单** 中可对 **指定用户** 开启「本地为其降噪」；仅影响 **本机收听** 该用户的下行音频，**不**改变对方上行，**不**经 SFU/服务端处理；名单 **跨端同步**。

### 1.2 关键原则

| 原则 | 说明 |
|------|------|
| **纯本地** | 降噪计算只在本机 CPU/GPU/WASM 完成；音频不上传第三方云降噪服务（除非未来单独产品决策）。 |
| **开源可审计** | 上架模型须为开源许可可再分发的实现（或浏览器引擎内置 API）；每个模型在 UI 标注名称、许可、大致算力。 |
| **SFU 无感** | SFU 仍纯转发（Server-15）；本地下行降噪不改 RTP 订阅关系（与「本地静音 = unsubscribe」不同）。 |
| **与现有链兼容** | 与 AEC/AGC、输入音量、每用户音量、本地静音、热迁移、仅听模式共存；优先级见 §5。 |
| **可选失败降级** | 某模型加载失败时提示并回退到安全档（浏览器内置或关闭），不得导致无法进语音。 |
| **偏好可同步** | 模型选择、NS 总开关、每用户本地降噪名单均属账号偏好，经用户设置文档跨端同步（见 §6）。 |

### 1.3 与现有能力边界

| 能力 | 文档 / 现状 | 与本功能关系 |
|------|-------------|--------------|
| NS 总开关 + AEC/AGC | 16 FR-10；`getUserMedia` 的 `noiseSuppression` 等约束 | 本文扩展为 **多模型** + **下行每用户**；浏览器约束仅为模型之一 |
| 每用户本地静音 | 16 FR-12；真实 `unsubscribe` | **正交**：静音 = 不收该路；本地降噪 = 仍收该路但本地处理 |
| 每用户音量 0–200% | voice store `userVolumes` | 降噪在音量增益 **之前**（§5.2）；音量仍可仅本机（与 NS 名单同步策略独立） |
| 热迁移双 PC | 13 | 迁移后对新链路重放：本人模型 + 每用户本地降噪名单 |
| 用户设置同步 | 16 / `settings-sync` | `ns` / `nsModel` / `localNs` 纳入可同步域 |

### 1.4 不在本期范围

- 云端 / 商业闭源降噪（Krisp 等）作为默认依赖。
- 服务端或 SFU 侧混流降噪。
- 对「整频道一键降噪所有人」的全局下行开关可作为 P1 快捷项，但 **不是** 替代每用户开关。
- 视频降噪、房间混响消除（Dereverb）专项（可后续模型槽位扩展）。
- 立体声「双声道分别降噪再合并」（P1 增强）；**P0 定稿为下混单声道后降噪**（§5.4）。

### 1.5 产品决议摘要（v0.2）

| # | 议题 | 决议 |
|---|------|------|
| R1 | 关闭 NS 总开关时，对他人「本地降噪」 | **暂停处理，名单保留**；再开总开关后按名单自动恢复 |
| R2 | 立体声开麦 + 降噪（P0） | **接受下混为单声道再降噪**；UI 须说明 |
| R3 | DeepFilterNet | **进入正式模型目录**（非仅实验开关） |
| R4 | 每用户本地降噪名单 | **跨端同步**（写入用户设置同步文档） |
| R5 | `localMuted` / `userVolumes` 是否随 `localNs` 跨端 | **维持仅本机**：二者强依赖设备听音环境；`localNs` 是对音源的判断故同步，标准自洽 |
| R6 | DeepFilterNet 下行同时降噪软上限 | **分模型定稿**：轻量模型 8 路、DeepFilterNet 4 路（均为 toast 软提示，不硬拦截） |
| R7 | 未来 DM/群组语音通话的降噪偏好 | **预决议复用**同一套 `nsModel` + `localNs`；以 DM 通话专项（Server-16 §1 后续项）定稿为准 |

## 2. 用户故事

| # | 场景 | 期望 |
|---|------|------|
| US-01 | 我在咖啡厅开麦 | 设置里打开降噪，选「RNNoise」，键盘声明显减弱；同频道的人反馈更清晰 |
| US-02 | 通话中从「浏览器内置」换成「RNNoise」或「DeepFilterNet」 | 1–2 秒内生效（重模型首次加载另计），不掉线、不回大厅 |
| US-03 | 某人背景有狗叫/电视 | 我右键他 →「本地为其降噪」；只有我这边听着干净，他和其他人不受影响 |
| US-04 | 低配电脑 | 可选「Speex / 轻量」或浏览器内置；选 DeepFilterNet 时有算力警告 |
| US-05 | 某模型 WASM 加载失败 | toast 说明，自动回退，语音仍可用 |
| US-06 | 我本地静音了某人 | 不拉流；本地降噪开关可保留偏好，取消静音后若曾开启则继续降噪 |
| US-07 | 热迁移换节点 | 迁移完成后本人降噪与对他人本地降噪偏好仍生效 |
| US-08 | 关闭 NS 总开关 | 上行不再走模型链；对他人本地降噪 **暂停出声处理但名单保留**；开关旁可提示「总开关已关」 |
| US-09 | 在电脑 A 给某人开了本地降噪，换电脑 B 登录 | 名单经云端同步后，B 端进入同一语音场景仍对该用户本地降噪 |
| US-10 | 立体声采集 + 开启 RNNoise/DeepFilterNet | 降噪按单声道处理（下混）；设置/试听有说明，不因此拒绝立体声开关 |

## 3. 模型目录（产品级）

### 3.1 正式目录（N ≥ 4，均须可本地运行）

实现可分阶段交付，但 **产品正式目录固定包含以下四档**（全部为本地、开源或浏览器内置）：

| 模型 ID | 显示名 | 技术来源（示例） | 许可方向 | 适用 | 算力 | 延迟观感 | 备注 |
|---------|--------|------------------|----------|------|------|----------|------|
| `browser` | 浏览器内置 | WebRTC `noiseSuppression` 约束 | 随 Chromium/WebKit | **仅上行（自己）** | 极低 | 极低 | 不保证对下行远端轨生效 |
| `rnnoise` | RNNoise | 开源 RNNoise + WASM/AudioWorklet | BSD 类（以实际上架包为准） | 上行 + 下行 | 中 | 低 | **推荐默认**（开启 NS 时） |
| `speex` | Speex 轻量 | SpeexDSP 预处理 NS 的 WASM/Worklet 移植 | BSD 类 | 上行 + 下行 | 低 | 极低 | 弱网/低配首选 |
| `deepfilternet` | DeepFilterNet | 开源 DeepFilterNet；ONNX Runtime / WASM 或 Tauri 原生侧加载 | 以实际上架包与模型许可证为准（须可再分发） | 上行 + 下行 | **高** | 中 | **正式目录**；首次选用须算力确认（§7.4）；权重可懒加载缓存 |

**可选扩展（非正式必选，目录可后续加）：**

| 模型 ID | 显示名 | 说明 |
|---------|--------|------|
| `spectral_gate` | 频谱门限（简易） | 纯 AudioWorklet 谱减法/门限，无大模型，作实验/兜底档 |

### 3.2 模型元数据（客户端必须展示）

每个模型在设置 UI 中展示：

- 显示名、一句话描述  
- 相对算力：低 / 中 / 高  
- 作用范围标签：`自己` / `自己+他人`  
- 开源项目名 + 许可证短名（可链到「关于」或外部文档）  
- 是否需要额外下载模型文件及大约体积（DeepFilterNet **必须**展示体积量级）  
- DeepFilterNet 额外标注：「高质量 · 较高 CPU/内存占用」

### 3.3 选型与上架规则

1. **可本地运行**：无强制联网推理；允许首次从应用包或同源 CDN **下载权重到本地缓存** 后离线使用。  
2. **可再分发**：许可证允许随 Owl-Desktop 分发或用户自动获取。  
3. **可热切换**：同一会话内可切换模型而不强制重进房。  
4. **可销毁**：关闭或换模型时释放 WASM/Worklet/AudioContext/原生会话相关资源，防泄漏。  
5. **单声道处理（P0）**：凡 WASM/ML 模型，**P0 一律按单声道处理**；立体声输入先下混（§5.4）。  
6. **DeepFilterNet 交付门槛**：须能在目标桌面平台完成懒加载 + 通话中热切 + 失败回退；若某平台暂无法交付，该平台可隐藏该档并记入发布说明，**不得**从产品目录定义中删除（其他平台仍展示）。

## 4. 功能需求明细（FR）

### 4.1 设置：对自己（上行）

- **FR-S01（总开关）** 语音设置保留「噪声抑制（NS）」总开关；默认 **开**（与 16 FR-10 一致）。  
- **FR-S02（模型选择）** 总开关下方提供「降噪模型」单选/下拉，列出 §3.1 正式目录中 **当前平台已实装** 的模型；未实装项不展示或标「本平台即将推出」。  
- **FR-S03（默认模型）** NS 开启时默认模型 = `rnnoise`（若未实装则 `browser`）。**不得**默认 `deepfilternet`（算力过高）。  
- **FR-S04（实时生效·上行）** 变更总开关或模型时：  
  - 若在语音中：重建 **本地上行处理链**（采集 → [下混若需要] → [可选模型] → [可选输入增益] → 编码轨），通过 `replaceTrack` 挂到现有 PC；**禁止**要求用户退出频道。  
  - 目标感知时延：已缓存权重时 **≤ 2s**；DeepFilterNet **首次**下载+加载允许更长，须显示进度，加载期间可临时沿用上一模型或静音上行突变策略由实现选择，但须避免长时间卡死 UI。  
- **FR-S05（浏览器模型约束）** 选择 `browser` 时：通过 `getUserMedia`/`applyConstraints` 启用 `noiseSuppression: true`；选择 WASM/ML 模型时：**关闭** 浏览器 `noiseSuppression`，避免双重处理导致发闷/失真（AEC/AGC 仍按用户开关独立控制）。  
- **FR-S06（强度 P1）** 若模型支持强度参数，提供滑杆（如 0–100，默认模型推荐值）；不支持则隐藏。推荐 **每模型记忆** 上次强度。  
- **FR-S07（试听）** 麦克风测试面板（16）在开启 NS 时应走 **与上行相同的模型链**（含立体声下混规则），用户能在测试回放中预览降噪效果。  
- **FR-S08（总开关与下行偏好）【决议 R1】** 关闭 NS 总开关时：  
  1. **必须**停止上行模型链（并按需恢复/关闭浏览器 NS 约束与立体声下混链）；  
  2. 对他人「本地降噪」：**暂停全部下行 NS 处理**（拆除或旁路处理节点以省算力）；  
  3. **`localNs` 名单必须保留**（不删除、不因关总开关而写入空列表到同步文档）；  
  4. 再次打开总开关后：按仍存在的 `localNs` 名单 **自动恢复** 对应用户的下行处理链；  
  5. UI：每用户「本地为其降噪」开关在总开关关闭时可保持勾选态，并附提示「降噪总开关已关闭，开启后将恢复」；或开关可操作但立即提示需先打开总开关（二选一，推荐 **保持勾选 + 文案提示**）。  

### 4.2 对他人：本地下行降噪

- **FR-R01（入口）** 对 **非自己** 的语音参与者，在以下入口提供开关（状态同源）：  
  1. 语音频道参与者卡片「⋯」菜单  
  2. 频道列表内语音用户 **右键菜单**（现有「本地音频」分组旁）  
  3. （P1）成员面板中「正在语音中」用户的右键  
- **FR-R02（文案）** 使用明确本地语义，避免被理解成服务器操作，例如：  
  - 「本地为其降噪」/「取消本地降噪」  
  - 描述：「仅你听起来更干净，不会改变对方设置」  
- **FR-R03（处理位置）** 本机收到该用户下行音频轨之后、扬声器输出之前，对该 **MediaStreamTrack/流** 做模型推理；**不**发送 `unsubscribe`（与本地静音区分）。  
- **FR-R04（使用的模型）** 下行每用户降噪 **默认使用设置中当前选中的模型**。  
  - 若当前模型仅支持上行（如 `browser`）：对他人开启时 **自动使用回退模型**（优先 `rnnoise`，若不可用则 `speex`），并在开关旁或首次开启时轻量提示「他人降噪将使用 RNNoise」。  
  - 若当前为 `deepfilternet`：下行同样可使用（受同时路数与性能约束 §FR-R09）；路数多时可提示改用轻量模型。  
  - **P1**：每用户可单独选模型（高级）；首期不做。  
- **FR-R05（实时生效·下行）** 打开/关闭某用户本地降噪：立即为该用户挂载/拆除处理链，**≤ 500ms** 可感知变化（DeepFilterNet 首帧可能略长）；不重进房。  
- **FR-R06（持久化与跨端同步）【决议 R4】**  
  - `localNs`（每用户是否开启本地下行降噪）为 **账号级偏好**，写入用户设置同步文档（与 `voice.ns` / `voice.nsModel` 同生命周期）；  
  - 经现有 `GET/PUT/PATCH /users/@me/settings` + `settings-sync` / `USER_SETTINGS_UPDATE` 跨端一致；  
  - 本地可保留缓存以供离线读取；冲突以服务端合并策略为准（16 同原则：防抖上行、远端事件合并）；  
  - 重连、热迁移、换设备登录后均须能重放名单。  
- **FR-R07（与本地静音）**  
  - 本地静音开启：信令退订，本机无下行音频 → 降噪链无输入，可销毁实例省算力；**不**因此从 `localNs` 移除；  
  - 取消本地静音：若名单中仍开启且 NS 总开关为开，则重新挂载处理链。  
- **FR-R08（与闭听 self_deaf）** 闭听时全部下行不播放；降噪链可暂停算力；名单保留。  
- **FR-R09（多人上限）** 同时对多人开启下行降噪时，客户端应：  
  - 软上限**分模型定稿（决议 R6）**：轻量模型（rnnoise / speex / 回退档）**8 路**、DeepFilterNet **4 路**；  
  - 超过软上限时 toast「同时降噪人数过多，可能影响性能」，仍允许开启；  
  - P1：设置中「下行降噪最大路数」可配。  
- **FR-R10（视觉反馈）** 对已开启本地降噪的用户，卡片或列表可选显示小图标；非必须 P0。  

### 4.3 资源加载与生命周期

- **FR-L01** 模型 WASM/权重：**懒加载**（首次选用该模型时加载），并缓存；设置页可显示「加载中…」与（DeepFilterNet）下载进度。  
- **FR-L02** 加载失败：toast + 回退（DeepFilterNet → `rnnoise` → `browser`）；写入诊断日志（16 日志规范，不含音频内容）。  
- **FR-L03** 离开语音 / 销毁 VoiceRtc：拆除全部上行/下行 NS 节点与临时 AudioContext，防止泄漏；**不**清除已同步的 `localNs` 偏好。  
- **FR-L04** 热迁移：CUTOVER 后对新链路重放上行模型与 `localNs` 名单（同音量/本地静音重放语义）。  

### 4.4 诊断与可观测

- **FR-D01** 语音调试信息（16 FR-14）增加只读字段：当前上行 NS 模型、是否加载成功、下行本地降噪用户数、NS 总开关状态。  
- **FR-D02** 高级区（P1）显示粗略 CPU 占用提示或「处理耗时 ms/帧」（若引擎可提供）；DeepFilterNet 优先展示。

## 5. 音频处理链与优先级

### 5.1 上行（自己 → SFU）

```text
麦克风设备
  → getUserMedia（AEC/AGC 按开关；browser NS 仅在模型=browser 时开）
  → [立体声下混为单声道]   ← P0：ns 开且模型为 WASM/ML 且实际为 2ch 时（决议 R2）
  → [NS 模型节点]          ← ns 开且模型为 rnnoise/speex/deepfilternet/…
  → [输入增益 Gain]        ← inputVolume ≠ 100% 时
  → RTCRtpSender track
  → SFU
```

说明：

- 模型 = `browser` 时：不走 WASM 节点；是否下混由浏览器/约束决定，**不强制**产品侧下混。  
- 模型 = WASM/ML 且立体声采集： **P0 必须先下混再进模型**（§5.4）。  

并行：监听轨 → 电平条 / 本地 VAD speaking；默认在 **NS 后** 取样（更接近他人听到的）。

### 5.2 下行（远端用户 → 本机扬声器）

```text
SFU → RTC 远端 track（按 user_id）
  → [若 NS 总开关开 且 该用户在 localNs] NS 模型节点
  → [每用户音量 × 主输出音量]
       · ≤100%：HTMLAudioElement.volume 或等效
       · >100%：GainNode 放大（现有逻辑）
  → 输出设备（setSinkId）
```

**顺序定稿：先降噪，后音量。**  

**总开关关闭时：** 即使 `localNs` 含该用户，也 **跳过** NS 节点（直通），名单仍在。

### 5.3 与本地静音

```text
本地静音 ON  → unsubscribe 音频 → 无下行轨 → 不跑 NS（名单保留）
本地静音 OFF → subscribe → 若总开关开且 localNs 则挂 NS
```

### 5.4 立体声【决议 R2 · P0 定稿】

- WASM/ML 降噪模型（`rnnoise` / `speex` / `deepfilternet` 等）在 **P0 仅保证单声道处理路径**。  
- 当用户开启立体声采集且实际上行出现 2 声道时：  
  - **先下混为单声道**（L/R 平均或等价能量保持策略，实现可选），再送入 NS 模型；  
  - 编码轨为降噪后的单声道（或按编码器习惯复制，但听感以单声道内容为准）。  
- UI **必须**说明，例如：  
  - 「使用 RNNoise / Speex / DeepFilterNet 时，立体声会先合并为单声道再降噪」  
  - 麦克风测试在立体声 + 上述模型组合下展示实际处理声道数。  
- **P1（非 P0）**：双声道分别降噪再合并；不阻塞本需求验收。  
- 关闭 NS 或改用 `browser` 模型后：不再强制产品侧下混，立体声采集行为回到 16 既有逻辑。  

### 5.5 采样率

- 模型链路应显式处理 48kHz（WebRTC 常见）与模型原生率；重采样责任在适配层，对产品透明。  
- DeepFilterNet 按所选实现的原生率适配，不得因采样率错误产生持续噪音或静音。

## 6. 数据模型（客户端）

### 6.1 用户设置（跨端同步 · 纳入 voice 或并列域）

```ts
type NoiseModelId =
  | "browser"
  | "rnnoise"
  | "speex"
  | "deepfilternet"
  | "spectral_gate" // 可选扩展

type VoiceSettings = {
  // 已有
  aec: boolean
  ns: boolean              // 总开关
  agc: boolean
  // 新增（同步）
  nsModel: NoiseModelId    // 默认 "rnnoise"
  nsStrengthByModel?: Partial<Record<NoiseModelId, number>> // P1
  /**
   * 对他人本地下行降噪名单（userId → true）
   * 【决议 R4】跨端同步；关总开关不清理
   */
  localNs: Record<string, true>
}
```

同步要求：

- `ns`、`nsModel`、`localNs` **必须**进入 `settings-sync` 的可同步载荷（与 16 通知/外观等一致）。  
- 若某端不支持 `deepfilternet`：拉取后 UI 显示「当前设备不支持，已本地使用 RNNoise」，**不**擅自把云端 `nsModel` 改写成 rnnoise 除非用户确认（避免他端被带崩）；运行时降级即可。  
- `localNs` 键为用户雪花/UUID 字符串；建议客户端限制名单规模（如最多 500 条），超出拒绝新增并提示。  

### 6.2 仅本机、不同步（对照）

| 项 | 同步？ | 说明 |
|----|--------|------|
| `localMuted` | **否（决议 R5 定稿）** | 真实退订，设备场景差异大 |
| `userVolumes` | **否（决议 R5 定稿）** | 本机听感，随输出设备变化 |
| `localNs` | **是（本决议）** | 用户明确的「谁吵」偏好，跨设备有价值 |
| 模型权重缓存文件 | 否 | 各端各自懒加载 |

### 6.3 运行时会话态（不持久化、不同步）

- 模型加载状态：`idle | loading | ready | error`  
- 每用户 NS 节点句柄、AudioContext  
- 「因总开关关闭而暂停」的运行时标记（名单仍来自 store）

## 7. UI / UX 要求

### 7.1 设置页（语音与视频 · 音频处理）

```text
音频处理
  ☑ 回声消除（AEC）
  ☑ 噪声抑制（NS）
      降噪模型  [ RNNoise（推荐） ▼ ]
                · 浏览器内置（仅自己）
                · RNNoise（自己+他人，开源）
                · Speex 轻量（自己+他人，开源）
                · DeepFilterNet（自己+他人，开源，高性能需求）
      说明：换模型将立即应用到当前通话

  ☑ 自动增益（AGC）
```

- 模型下拉在 NS 关闭时禁用或灰置。  
- 选中仅上行模型时，辅助文案：「对其他用户的「本地降噪」将使用 RNNoise」。  
- DeepFilterNet：算力徽章「高」+ 体积提示。  

### 7.2 参与者菜单

```text
本地音频 · 当前音量 xx%
  用户音量 → …
  本地静音
  耳机静音
  ☑ 本地为其降噪
     仅你侧处理，对方无感；将在多端同步
```

- NS 总开关关闭时：勾选可保留，副文案「降噪总开关已关闭」。  
- 卡片 Popover 与右键菜单状态同源。  

### 7.3 文案与无障碍

- 避免「服务器降噪」「强制降噪」等措辞。  
- 开关提供 `aria-checked`；模型选择有可聚焦标签。  
- 错误 toast 示例：「DeepFilterNet 加载失败，已回退到 RNNoise」。  

### 7.4 性能与安全提示

- **DeepFilterNet 首次选择**（每账号可只弹一次）：确认对话框——「可能显著增加 CPU 与内存占用，低配设备建议使用 RNNoise 或 Speex」。用户确认后写入本地「已确认」标记（可不进云端）。  
- 不在 UI 承诺「100% 去除所有噪音」。

## 8. 非功能需求

| 指标 | 要求 |
|------|------|
| 上行换模型时延 | 已缓存权重时 ≤ 2s 可说话听到效果 |
| DeepFilterNet 首次加载 | 显示进度；不阻塞整个设置页滚动；超时（如 60s）可取消并回退 |
| 下行开关单用户 | ≤ 500ms（轻量模型）；DeepFilterNet 允许首帧略长 |
| 额外单路 RNNoise CPU | 中档笔记本一路上行 < 5% 量级为目标（压测校准） |
| 同时下行 NS 软上限 | 轻量模型 8 路；DeepFilterNet 4 路（决议 R6，均为 toast 软提示） |
| 内存 | 离开语音后实例可卸载；权重缓存可保留 |
| 隐私 | 音频采样不落盘、不上报；日志不含 PCM；同步文档仅含 userId 名单与模型 id |
| 兼容 | Tauri + 系统 WebView；AudioWorklet/原生推理不可用时隐藏对应模型 |
| 同步 | `localNs` 变更防抖写入 settings（与现有 1.5s 量级策略一致），多端 ≤ 数秒内收敛 |

## 9. 边界与异常

| 场景 | 行为 |
|------|------|
| AudioWorklet 不支持 | 隐藏/禁用 WASM 档；DeepFilterNet 若走原生侧可仍可用 |
| 模型加载中用户连点切换 | 以最后一次选择为准，取消过期加载 |
| 仅听模式（无麦） | 上行 NS 不适用；下行每用户 NS 仍可用 |
| 对方未说话 / 无轨 | 不创建 NS 实例或 idle 省电 |
| 输入设备热切换 | 按 16 重采麦，并重新挂载上行 NS（含下混） |
| 双重 NS 发闷 | 强制 browser 与 WASM/ML 不同时开启（FR-S05） |
| 关闭总开关 | 暂停所有 NS 处理；**名单保留并继续同步**（R1） |
| 他端清空名单 | 本端经 `USER_SETTINGS_UPDATE` 合并后停止对应下行 NS |
| 立体声 + WASM NS | 下混单声道（R2）；关闭 NS 后恢复非强制下混 |
| 群组成员大量开启下行 NS | 软上限 toast；DeepFilterNet 更早提示 |
| 同步文档体积 | `localNs` 过大时拒绝新增并提示清理 |

## 10. 验收标准

| # | 验收项 | 通过条件 |
|---|--------|----------|
| AC-01 | 正式模型列表 | 设置中可展示 browser / rnnoise / speex / deepfilternet（平台已实装者），含开源/算力/范围说明 |
| AC-02 | 上行实时切换 | 通话中切换模型不掉线；含切换到/自 DeepFilterNet（已缓存时） |
| AC-03 | 默认与开关 | NS 默认开、默认模型 rnnoise；关总开关后上行无 WASM/ML 链 |
| AC-04 | 总开关保留名单（R1） | 对用户 A 开本地降噪 → 关总开关 → A 听感恢复未处理且开关仍显示已选 → 再开总开关 → A 自动再降噪；同步文档中仍有 A |
| AC-05 | 麦克风测试 | 测试回放与通话上行同一模型；立体声+ML 时可见单声道处理说明 |
| AC-06 | 右键本地降噪 | 对用户 A 开启后仅本机听感变化；用户 B 听 A 不变 |
| AC-07 | 与本地静音正交 | 静音后退订；取消静音后降噪偏好恢复（总开关开时） |
| AC-08 | 跨端同步（R4） | 端 A 写入 localNs 与 nsModel → 端 B 登录或收 settings 事件后一致并可重放 |
| AC-09 | 立体声下混（R2） | 立体声采集 + rnnoise/speex/deepfilternet 时处理链为下混后单声道；UI 有说明 |
| AC-10 | 热迁移 | 迁移后上行模型与下行名单仍生效 |
| AC-11 | 失败降级 | DeepFilterNet 资源损坏时回退 rnnoise/browser 且语音可用 |
| AC-12 | 资源释放 | 离开频道后无持续处理占用；名单偏好仍在 |
| AC-13 | 音量顺序 | 先 NS 后 >100% 增益 |
| AC-14 | 文案 | 无「服务器将为对方降噪」类误导；DeepFilterNet 有算力提示 |

## 11. 实现分期建议（供排期，非本需求强制）

| 阶段 | 范围 |
|------|------|
| **M1** | 模型目录 UI + `ns`/`nsModel` 同步；`browser` + `rnnoise` 上行；实时 replaceTrack；立体声下混（R2） |
| **M2** | 下行每用户本地降噪 + 右键/卡片；`localNs` **跨端同步**（R4）；总开关暂停保留名单（R1） |

| **M4** | **`deepfilternet` 正式交付**（懒加载、确认弹窗、热切、回退）；分模型下行路数软上限 |
| **M5 P1** | 强度滑杆、每用户独立模型、双声道分别降噪、同时路数用户可配、试听对比 |

技术选型由实现阶段定（AudioWorklet / ONNX / Tauri 原生等），**不得改变** 本文产品语义与四项决议。
