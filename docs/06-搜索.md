## 1. 功能概述

本文档定义 Newt-Desktop 的消息搜索体验，覆盖：

- **全系统搜索**：跨服务器 / 全局检索能力（07 文档 5B.5 产品定稿：要做全系统搜索）；权限上只命中调用者可见内容——成员身份 + `VIEW_CHANNEL` + 无禁看 Restriction 的频道并集（13 文档 AU.3），ACL 过滤由服务端检索层强制注入，客户端不承担权限过滤职责。
- **搜索入口与快捷键**：全局 `Ctrl/Cmd+K` 快速切换器（Quick Switcher，对标 Discord），频道/服务器内搜索框 `Ctrl/Cmd+F`（对标 Discord 频道搜索）。
- **搜索过滤器**：`from:` `in:` `has:` `before:` `after:` 等结构化过滤语法，对标 Discord 搜索语法，映射到服务端查询参数（13 文档 AU.4：guild、channel、author、时间范围）。
- **结果展示与跳转**：右侧结果面板分页展示，点击结果跳转到消息在频道中的上下文位置并高亮。
- **搜索历史**：本地保存最近搜索词与过滤器组合，快速重放。

服务端能力边界（13 文档 AU 系列）：搜索引擎为 OpenSearch/Elasticsearch 类专用索引；索引更新异步秒级；**只搜当前正文**，不搜历史编辑版本（AU.7）；软删消息出索引；按用户严格限流（AU.8）。客户端体验需围绕这些边界设计（如「刚发的消息可能几秒后才可搜到」的预期管理）。

## 3. 功能需求明细（FR）

### 3.1 搜索入口与快捷键

- **FR-01 全局快速切换器**：`Ctrl/Cmd+K` 打开全局搜索浮层（对标 Discord Quick Switcher）：空输入时显示搜索历史与最近访问的频道/服务器；输入文本后上半区显示频道/成员/服务器名称匹配（本地缓存匹配，即时响应），下半区提供「搜索消息：'关键词'」入口进入消息搜索。
- **FR-02 频道内搜索**：每个服务器界面右上常驻搜索框，点击或 `Ctrl/Cmd+F` 聚焦；默认作用域为当前服务器，输入 `in:` 可窄化到具体频道（对标 Discord 服务器顶栏搜索框）。
- **FR-03 作用域切换**：搜索框下拉提供三档作用域：**当前频道 / 当前服务器 / 全部服务器（全局）**；全局档对应不传 `guild_id` 的全系统搜索（13 AU.3）。默认记住上次选择。
- **FR-04 Esc 关闭**：任意搜索浮层/面板 `Esc` 关闭并归还焦点到消息输入框（对标 Discord）。
- **FR-05 触发时机**：消息搜索为显式提交（Enter 或点击搜索入口）触发，不做每键即搜，配合服务端按用户限流（13 AU.8）；名称类匹配（FR-01 上半区）为本地即时。

### 3.2 搜索过滤器语法

- **FR-06 支持的过滤器**（对标 Discord 搜索语法，映射到 13 AU.4 / §7.1 查询参数）：

| 语法 | 含义 | 服务端参数 | 备注 |
|------|------|-----------|------|
| `from:用户` | 指定作者 | `author_id` | 输入时弹成员补全 |
| `in:频道` | 指定频道 | `channel_id` | 输入时弹频道补全（仅可见频道） |
| `before:YYYY-MM-DD` | 该日期之前 | `before` | 弹日期选择器 |
| `after:YYYY-MM-DD` | 该日期之后 | `after` | 弹日期选择器 |
| `has:link / file / image / video / audio / reply` | 含特定元素 | — | 服务端未定义 has 过滤，见 §8；首期可客户端隐藏未支持项 |
| `mentions:用户` | 提及某人 | — | 服务端未定义，见 §8 |

- **FR-07 过滤器补全**：聚焦搜索框显示可用过滤器提示列表；键入 `from:` 等前缀后弹出对应实体选择器，选择后以彩色胶囊 token 呈现在输入框内，可整体删除（对标 Discord filter pill）。
- **FR-08 组合查询**：支持多过滤器 + 自由文本组合（如 `from:Alice in:#公告 版本`）；同类过滤器多值行为以服务端为准，首期同类仅允许一个，重复键入时替换旧值。
- **FR-09 语法容错**：无法解析的过滤器前缀按普通文本处理，不报错阻断。

### 3.3 搜索执行与权限

- **FR-10 调用**：`GET /search/messages?q=&guild_id=&channel_id=&author_id=&before=&after=&limit=`（13 §7.1）；客户端仅传用户显式选择的过滤条件，**绝不传递任何权限旁路参数**（服务端强制 ACL 注入，13 §7.1）。
- **FR-11 可见性保证（展示侧配合）**：搜索结果的可见性完全由服务端保证；客户端不做二次过滤，但若结果中的频道在本地缓存不可见（竞态：刚被禁看），点击跳转收到 404 时按「频道不可用」处理，不暴露存在性（06 §8、13 §10）。
- **FR-12 索引延迟预期**：结果面板底部固定注释「消息索引可能有数秒延迟」（13 AU.6）；刚发送的消息搜不到不视为缺陷。
- **FR-13 不搜编辑历史**：仅命中消息当前正文（13 AU.7）；产品文案与帮助说明不得暗示可搜旧版本。
- **FR-14 限流处理**：收到 429 时结果区显示「搜索过于频繁，请 N 秒后重试」（13 AU.8），期间禁用搜索提交按钮并倒计时。
- **FR-15 分页**：结果按相关度或时间排序（以服务端返回为准）分页加载，`limit` 默认 25/页；结果面板滚动到底自动加载下一页，顶部显示总命中数（若服务端返回 total）。

### 3.4 结果展示与跳转

- **FR-16 结果面板**：搜索结果在主界面右侧滑出面板展示（对标 Discord 搜索面板）：每条结果为一张消息卡片——服务器/频道面包屑、作者头像昵称、时间、正文（关键词高亮 `<mark>`）、附件/回复图标。
- **FR-17 关键词高亮**：命中词在结果卡片内高亮；若服务端返回 highlight 片段则用之，否则客户端按查询词本地高亮。
- **FR-18 上下文跳转**：点击结果卡片：主消息区切换到目标频道，以目标消息为锚点加载其前后上下文（用消息 ID 作 `before`/`after` 各拉一页，13 AR.2），滚动定位并高亮闪烁 2s（对标 Discord jump 行为）。
- **FR-19 跳转历史权限**：若用户对目标频道无 `READ_MESSAGE_HISTORY`，理论上搜索也不应命中历史（以服务端 ACL 为准）；若边缘竞态下跳转失败（404），toast「无法定位该消息」。
- **FR-20 卡片内快捷操作**：结果卡片 hover 提供「跳转」按钮；右键提供「复制消息链接」。
- **FR-21 空态**：无结果时显示空态插画 + 文案「未找到与 'xxx' 匹配的消息」+ 常用语法示例（对标 Discord 空态教育）。
- **FR-22 分组维度**：全局搜索结果按服务器分组，组头显示服务器名与该组命中数；服务器内搜索按时间倒序平铺（新→旧，对标 Discord 默认新排前）。

### 3.5 搜索历史

- **FR-23 本地保存**：最近 20 条搜索（查询词 + 过滤器组合 + 作用域）存储在本地（按账号隔离），不上传服务端。
- **FR-24 历史展示**：搜索框聚焦且为空时下拉展示最近 5 条，带「清除全部」入口；单条右侧「×」可删除。
- **FR-25 历史重放**：点击历史条目完整还原过滤器 token 与作用域并立即执行。
- **FR-26 隐私**：登出或切换账号时不清空但需按账号隔离读取；用户在设置中可关闭搜索历史记录功能。

### 3.6 快速切换器（Ctrl/Cmd+K）细节

- **FR-27 匹配数据源**：上半区名称匹配基于本地缓存：已加入服务器名、可见频道名（含 `#` 前缀过滤文字频道、`!` 前缀过滤语音频道、`@` 前缀过滤成员、`*` 前缀过滤服务器，对标 Discord Quick Switcher 前缀语法）。
- **FR-28 匹配排序**：按「精确前缀 > 词首匹配 > 模糊匹配」排序，同级按最近访问时间加权；最多显示 10 条。
- **FR-29 直达跳转**：选中频道条目 Enter 直接切换到该频道；选中成员条目打开成员卡片；选中「搜索消息」条目携带当前输入进入消息搜索（作用域默认全局）。
- **FR-30 可见性一致**：切换器数据源仅包含当前可见实体；被禁看频道随 Gateway 事件从缓存移除后立即不可匹配（与 08 文档 FR-27 禁看语义一致）。

### 3.7 结果缓存与性能

- **FR-31 结果缓存**：同一查询（词 + 过滤器 + 作用域）5 分钟内重复执行直接使用内存缓存并后台静默刷新（stale-while-revalidate），减少限流压力（配合 13 AU.8）。
- **FR-32 请求去抖与取消**：新查询提交时取消在途旧请求；面板关闭时取消所有在途搜索请求。
- **FR-33 分页游标**：翻页参数（offset/cursor）以服务端响应为准；游标失效（如索引更新导致）时从第一页静默重拉，不向用户报错。

## 4. UI / UX 要求

- **UX-01 面板布局**：结果面板宽度约 420px，可拖拽调节；打开时压缩成员列表区而非覆盖消息区（对标 Discord 搜索面板挤占行为）。
- **UX-02 加载态**：搜索执行中结果区显示骨架屏（3–5 张灰色卡片），避免闪烁；超过 5s 显示「仍在搜索…」。
- **UX-03 过滤器 token 视觉**：过滤器胶囊使用「键名灰 + 值蓝」双色 token，与自由文本明显区分；退格键先整体选中 token 再删除（对标 Discord）。
- **UX-04 键盘导航**：结果面板支持 `↑↓` 在卡片间移动、`Enter` 跳转、`Esc` 关闭；`Ctrl/Cmd+K` 浮层同样全键盘可达。
- **UX-05 高亮动画**：跳转定位后目标消息背景以品牌色 20% 透明度闪烁两次后淡出，不残留常驻高亮。
- **UX-06 中文支持**：查询词分词交由服务端引擎；客户端保证 IME 组合输入期间不误触发提交（Enter 需在组合结束后才生效）。
- **UX-07 性能**：结果卡片虚拟滚动，千条结果不卡顿；跳转上下文加载目标 <1s（缓存命中时即时）。
- **UX-08 状态保持**：关闭结果面板后再次打开（同一会话内）恢复上次查询与结果，无需重新请求。
- **UX-09 快捷键提示**：快速切换器底部常驻一行前缀语法提示（`# 频道 · @ 成员 · * 服务器`），帮助用户发现前缀过滤能力（对标 Discord Quick Switcher 底部提示）。
- **UX-10 深浅色与无障碍**：高亮 `<mark>` 颜色在深浅主题下均满足对比度要求；结果卡片提供完整 aria-label（作者、时间、频道、正文摘要）供屏幕阅读器朗读。

## 5. 与服务端的交互

| 交互 | API / 事件 | 权限语义 | 出处 |
|------|-----------|---------|------|
| 消息搜索 | `GET /search/messages?q=&guild_id=&channel_id=&author_id=&before=&after=&limit=` | 服务端强制注入 ACL：成员 + `VIEW_CHANNEL` + 无禁看 Restriction 的可见频道并集 | 13 §7.1、AU.3 |
| 跳转上下文加载 | `GET /channels/{id}/messages?before=&after=&limit=` | `VIEW_CHANNEL` + `READ_MESSAGE_HISTORY` | 13 AR.2/AR.3 |
| 限流 | HTTP 429 + retry_after | 按用户严格限流 | 13 AU.8 |
| 不可见频道 | HTTP 404 | 不暴露存在性 | 06 §8、13 §10 |

关键约定：

1. 搜索范围 = 调用者可见 guild/channel 并集，禁看 Restriction 生效中的频道不命中（13 AU.3、12 §6.2 `view_text`）。
2. 索引异步更新秒级（13 AU.6），软删消息出索引（13 §7.1）；客户端对「搜到但跳转 404」按竞态容错处理。
3. 排序、总数、highlight 片段等响应结构以 OpenAPI 正式稿与索引 mapping 为准（13 §13）。

## 6. 边界与异常情况

| 场景 | 客户端行为 |
|------|-----------|
| 搜索结果指向的消息刚被删除 | 跳转时目标不存在：定位到相邻消息并 toast「该消息已被删除」 |
| 搜索结果指向的频道刚被禁看 | 上下文接口 404 → 按「频道不可用」处理，从频道列表移除，不提示「无权限」 |
| 查询词为空但带过滤器 | 允许提交（如 `from:Alice` 列出其全部可见消息），以服务端支持为准；服务端 400 时提示「请输入关键词」 |
| 查询词过短（1 字符） | 允许提交，交由服务端；命中过多时依赖分页 |
| 429 限流 | FR-14 冷却倒计时；期间历史与已加载结果仍可浏览 |
| 网络错误 / 5xx | 结果区显示重试按钮，不清空已有结果 |
| 全局搜索跨大量服务器超时 | 显示部分结果 +「结果可能不完整」提示（若服务端支持 partial）；否则整体失败重试 |
| IME 组合中按 Enter | 不提交（UX-06） |
| 服务器被封禁/退出后的旧搜索历史 | 重放时按当前可见性执行，命不中即空态，不报错 |
| 搜索面板打开时收到目标频道 MESSAGE_DELETE | 已渲染结果不强制实时刷新，跳转时兜底处理 |
| 查询词含过滤器保留字（如正文本身含 `from:`） | 支持引号转义 `"from:"` 按字面量搜索；无引号时按过滤器优先解析 |
| 结果缓存期间权限变化（新增禁看） | 后台静默刷新（FR-31）会以最新 ACL 结果覆盖缓存；跳转时 404 兜底 |
| 客户端离线状态 | 搜索入口可打开但提交时提示「当前离线，无法搜索」；历史仍可浏览 |
| 超长查询词（>512 字符） | 客户端截断提示，以服务端长度限制为准 |

## 7. 验收标准

1. `Ctrl/Cmd+K` 在任意界面 100ms 内打开浮层；输入频道名前缀可本地即时匹配并 Enter 跳转。
2. 服务器内搜索 `from:Alice 报表`：结果全部为 Alice 所发且含「报表」，过滤器以 token 胶囊呈现，退格可整体删除。
3. `before:` / `after:` 过滤生效：结果时间范围与选择日期一致（以服务端 UTC 判定）。
4. 权限验证：给 B 施加某频道禁看 Restriction 后，B 用该频道内独有关键词搜索，0 命中；解除后（索引延迟内）可命中。
5. 全局作用域：A 加入 3 个服务器，搜索通用词可命中全部 3 个服务器的消息且按服务器分组；未加入的服务器绝不出现。
6. 跳转：点击结果后主消息区定位到目标消息并闪烁高亮，前后上下文各至少一页可继续滚动。
7. 新发送消息在数秒内可被搜索命中（索引延迟 ≤10s 视为达标，参考 13 AU.6 秒级承诺）。
8. 编辑消息后旧正文不再命中、新正文可命中（AU.7 验证）。
9. 连续快速搜索触发 429 时出现倒计时提示，冷却后自动恢复可用。
10. 搜索历史：执行 6 次搜索后聚焦空搜索框显示最近 5 条，点击重放结果一致；设置中关闭历史后不再记录。
11. 空态：搜索随机字符串显示空态插画与语法示例，无报错。
12. 断言客户端请求：抓包确认除文档列出的参数外未发送任何额外权限类参数。
13. 快速切换器前缀：输入 `#公` 仅匹配文字频道、`@Al` 仅匹配成员、`*Owl` 仅匹配服务器；被禁看频道施加后立即无法通过切换器匹配到。
14. 结果缓存：5 分钟内重复同一查询不产生新的搜索请求（抓包验证），面板内容即时呈现。
