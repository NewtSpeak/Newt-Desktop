## 1. 功能概述

频道（Channel）是服务器内的内容与语音单元。本文档定义桌面客户端的频道体系需求：

- **频道类型**：文本频道、语音频道（首期，出处：06 §3 首期范围）；公告频道、舞台频道作为可扩展类型预留（语音频道的「舞台模式」首期即有，见下）。
- **频道分组/分类（Category）**：对标 Discord 的可折叠分类。
- **频道 CRUD 与排序**：创建 / 编辑 / 删除 / 拖拽排序，受 `MANAGE_CHANNELS`（bit 4）控制。
- **频道 topic**：文本频道主题，显示在频道头部。
- **语音频道模式**：自由讨论 / 舞台模式，可配置（出处：07 专项 3 §3.1）；含人数上限、>50 强制舞台与自动禁说、麦序/抱麦、协管。
- **入场语音包频道开关**：每个子频道管理员可配置本频道是否允许播放入场语音包（出处：07 5A.1b）。
- **频道可见性**：无 `VIEW_CHANNEL` 则频道整体不可见；被「禁看」时服务端 API 返回 404 且 Gateway 不推送（出处：06 §8、02 §11、07 专项 4 注意 1）。

## 3. 功能需求明细（FR）

### 3.1 频道类型与列表

- **FR-01 频道类型枚举**：客户端支持 `TEXT`（#）、`VOICE`（🔊）、`CATEGORY`；类型枚举预留 `ANNOUNCEMENT`（📣 公告）与 `STAGE`（舞台专用频道）扩展值；**私信类型 `DM` / `GROUP_DM`** 见 [文档 19](./19-隐私设置好友与私信.md)（无 `guild_id`，不在服务器频道列表渲染）。收到未知类型时降级为只读文本展示（前向兼容）。
- **FR-02 频道列表布局**：服务器图标右侧为频道列表栏（约 240px）：顶部服务器名 + 下拉菜单，下方按 `position` 排序渲染分类与频道，对标 Discord 频道列表。
- **FR-03 分类折叠**：分类可点击折叠/展开（状态存本地）；折叠时仍显示其中「有未读或有人在语音中」的频道（Discord 惯例）。
- **FR-04 未读指示**：有未读消息的文本频道名变白色加粗 + 左侧白点；@提及显示红色数字徽标；已读灰化。
- **FR-05 语音频道成员展示**：语音频道名下实时缩进展示房内成员（头像 + 昵称 + 状态图标：闭麦/闭听/直播中），说话者头像加绿色描边（数据源：Gateway `VOICE_STATE_UPDATE` 与 SFU `speaking` 事件，出处：06 §9、协议 README §2.2）。
- **FR-06 人数显示**：语音频道右侧显示「当前人数/上限」；达到上限后频道名灰化，点击提示「频道已满」（硬上限 200，出处：06 §1.2）。

### 3.2 频道创建 / 编辑 / 删除 / 排序

- **FR-07 创建入口**：分类行悬停「+」或服务器菜单「创建频道」；弹窗选择类型（文本/语音）、输入名称（文本频道名自动转小写连字符风格可作 P1，首期原样）、可选「私密频道」开关（开启后进入 04 文档的初始 overwrite 配置：对 `@everyone` deny `VIEW_CHANNEL`，并勾选可见角色/成员，交互完全对标 Discord Private Channel 向导）。
- **FR-08 权限门槛**：创建/编辑/删除/排序均要求服务器级 `MANAGE_CHANNELS`（bit 4，出处：02 §3.2、§8「创建频道 = 服务器 MANAGE_CHANNELS」）；频道级 `MANAGE_CHANNELS` overwrite 允许管理单个频道。无权限时相关入口隐藏。
- **FR-09 编辑页**：频道齿轮进入频道设置：概览（名称 / topic / 慢速模式 P1 / 人数上限〔语音〕/ 语音模式〔语音〕/ 入场语音包开关）、权限（见 04 文档 overwrite 编辑器）、邀请、删除频道。
- **FR-10 topic**：文本频道 topic ≤1024 字符；显示在聊天区顶栏，超长省略号，点击展开完整弹窗（Discord 惯例）。
- **FR-11 删除确认**：删除频道弹确认框，明示「消息记录将不可恢复」；语音频道内有人时警告将断开他们。
- **FR-12 拖拽排序**：支持拖拽频道调整 `position`、跨分类移动、拖动分类整体排序；释放后批量提交，失败回滚并 toast。〔需服务端补充 API：频道 CRUD 与批量排序，如 `POST /guilds/:id/channels`、`PATCH /channels/:id`、`PATCH /guilds/:id/channels`(positions)〕
- **FR-13 分类内新建继承**：在分类下创建的频道默认继承该分类的权限 overwrite（对标 Discord「与分类同步」；同步状态标识与「已不同步」提示见 04 文档 FR）。

### 3.3 频道可见性（核心约束）

- **FR-14 不可见即不存在**：对最终权限无 `VIEW_CHANNEL`（bit 10）的频道：不渲染于频道列表、不出现在搜索/@频道自动补全、通知一律不产生（出处：02 §5.4 隐含规则「无 VIEW_CHANNEL 频道对用户不可见」）。
- **FR-15 404 语义**：客户端对任何频道请求收到 404 时，一律按「频道不存在」处理并从本地缓存移除该频道，**不得**提示「无权限」（服务端定稿：无权限统一 404 防扫频，不用 403，出处：06 §8）。
- **FR-16 Gateway 静默**：服务端对不可见频道不推送任何事件（06 §8）；客户端因此必须在**权限恢复**时依赖 `PERMISSIONS_UPDATE` 类事件或重拉频道列表来补全（重拉时机：收到自身角色/overwrite 变更事件后）。
- **FR-17 实时消失**：正浏览的频道被撤销 `VIEW_CHANNEL` 或被施加「禁看」Restriction（07 专项 4）时，客户端收到相应事件后立即将用户导航离开该频道（回到该服第一个可见频道或主页），并从列表移除；正输入的草稿保留在本地以备权限恢复。
- **FR-18 禁看 ≠ 禁言展示**：被限制「文字·观看」按不可见处理；仅被限制「文字·发言」时频道可见可读，输入框禁用并显示「你被禁言至 {到期时间}：{原因}」（当事人可见原因与到期，出处：07 §4.6）。

### 3.4 语音频道：进出与基础体验

- **FR-19 一键进房**：单击语音频道即发起 `POST /voice/join`（主路径，出处：06 §9），获得 media token / 节点 / caps 后按协议 README §2 与 SFU 建立 WSS + WebRTC；进房条件为 `VIEW_CHANNEL + CONNECT`（02 §5.4）。
- **FR-20 语音状态栏**：进房后左下用户栏上方出现语音连接卡片：连接质量、频道名、断开按钮、（预留）屏幕共享按钮；对标 Discord Voice Connected 面板。
- **FR-21 旁听态**：有 `CONNECT` 无 `SPEAK` 的用户可进房只听（02 §5.4「旁听/听讲模式听众」）；麦克风按钮灰置并 tooltip「你在此频道无发言权限」。
- **FR-22 token 生命周期**：media token TTL 2–5 分钟，客户端在过期前经 `POST /voice/refresh-token` 刷新并用 `auth` 帧在位更新（出处：协议 README §1、§2.3）。
- **FR-23 caps 实时变更**：收到 SFU `caps_updated`（如被禁言、被抱下麦）后 UI 立即反映：失去 `publish_audio` → 麦克风强制闭合且不可自行打开；收到 `closed` 按关闭码分支处理（§6）。
- **FR-24 热迁移无感**：收到 `VOICE_SERVER_UPDATE`（辅路径，06 §9）指示换节点时，客户端自动向新节点重建会话，允许短暂静音，**禁止**任何「回大厅/手动重进」交互（出处：07 专项 1 §1.1）；迁移期间语音卡片显示「正在切换线路…」微提示。
- **FR-25 RTT 探测**：进房前对服务端下发的候选节点并发 `GET /rtt` 探测并回传结果供调度（出处：协议 README §2、07 §2.3）。
- **FR-26 本地静音他人**：右键房内成员可「本地静音」，实现为向 SFU 发 `unsubscribe`（真实停止转发，节省带宽，出处：协议 README §2.1「静音 = 退订」）；取消静音发 `subscribe`。

### 3.5 语音频道模式：自由讨论 / 舞台

依据 07 专项 3 定稿：

- **FR-27 模式配置**：语音频道设置提供模式单选：**自由讨论**（默认，全双工互听）/ **舞台**（台上发言、台下听讲）；台上目标上限可配 1–50，默认 20（软限 20 / 硬顶 50，硬顶不可配置超过 50，出处：07 §3.2）。人数上限可配，软上限 50、硬上限 200（06 §1.2）。
- **FR-28 舞台 UI**：舞台模式下房间视图分区：「舞台」区（台上发言者大头像网格）与「听众」区（小头像列表）；对标 Discord Stage Channel 布局。
- **FR-29 申请上麦**：听众点「举手」进入麦序队列（`REQUEST_TO_SPEAK` 位预留启用，出处：02 §11）；队列面板对管理员/协管可见，支持同意（抱上）、拒绝、调整；可配置「关闭申请，仅抱麦」（07 §3.4）。
- **FR-30 抱上/抱下**：管理员/协管可直接抱任意听众上麦、抱任意台上者下麦；被抱上者收到确认提示（可选择拒绝），被抱下者 caps 即时收回（Server→SFU 控制通道即时生效，出处：07 专项 3 注意 3）。
- **FR-31 >50 自动禁说**：自由讨论频道人数超过 50 且未切舞台时，客户端向管理员展示「建议切换舞台模式」横幅；第 51 人起进房者显示「因人数超限你已被自动禁说（可听）」，其状态图标带特殊角标；有人离开后按进房顺序解除，被解除者收到「你已恢复发言资格」toast（出处：07 §3.1）。该自动禁说来源标记为 `CAPACITY_QUEUE`，管理 UI 中与人工禁言明确区分（07 专项 3 注意 2）。
- **FR-32 听众选择性收听**：听众默认订阅全部台上音频（07 §3.3）；可对单个发言者本地静音（FR-26 的 `unsubscribe`），实现「只听主咖」等自由组合。
- **FR-33 协管任命**：频道设置「协管」页：频道管理员维护协管列表（从成员中搜索添加），协管权限节点可勾选（麦序管理、抱上/抱下、频道内禁说等），不得超越服级授权上限（出处：06 §1.4、07 §3.5）。〔需服务端补充 API：舞台/麦序/协管信令与 REST，服务端已列为衍生专项 3〕
- **FR-34 小房舞台**：≤50 人频道同样允许开启舞台模式（讲座场景，07 §3.6）。

### 3.6 入场语音包（频道维度）

- **FR-35 频道开关**：语音频道设置含「允许播放入场语音包」开关，默认开；仅该频道管理员（频道级 `MANAGE_CHANNELS` 或协管被授节点）可改（出处：07 5A.1b「每个子频道管理员可配置本频道是否允许播放」）。
- **FR-36 播放行为**：收到入场语音包事件（`VOICE_PACK_PLAY` 或进房事件携带 `voice_pack_id`，出处：06 §9.1）后，客户端拉取短音频 URL 本地播放（**不经 SFU 长轨道**，07 5A.3）；本频道开关为关时忽略事件。
- **FR-37 触发范围**：默认「进服首次出现 / 进指定语音频道」触发、同语音频道成员可听（07 5A.1、5A.2）；客户端另提供个人级「静音所有入场音效」偏好开关（本地）。
- **FR-38 音量与打断**：入场音效音量挂在「音效」音量类别下可调；同时多条时排队播放，队列超过 3 条丢弃最旧（防刷屏）。

### 3.7 文本频道基础（与消息文档的边界）

- **FR-39 消息收发门槛**：发送需 `VIEW_CHANNEL + SEND_MESSAGES`；拉历史需 `READ_MESSAGE_HISTORY`（02 §5.4）；无历史权限时仅显示进入频道后的新消息，顶部提示「你没有查看历史消息的权限」。
- **FR-40 附件**：允许上传各类附件；仅 PDF/音频/视频/图片提供内嵌预览，其余显示下载卡片（07 5B.3）；上传前按本服单文件大小上限（系统管理员按服配置，07 5B.3b）本地预校验。
- **FR-41 编辑标记**：编辑过的消息显示「（已编辑）」并 hover 显示编辑次数（次数以服务端为准，07 5B.4）。
- 消息系统（输入框、Markdown、表情回应、搜索等）的完整需求另立 05 文档，本文不展开。

## 4. UI / UX 要求

1. 频道列表交互全面对标 Discord：# 与 🔊 图标、分类小写标签、悬停出现「邀请 / 设置」快捷图标、右键上下文菜单。
2. 语音频道内说话绿圈延迟 ≤250ms（对齐 SFU `speaking` 事件 ~250ms 节流，协议 README §2.2）。
3. 拖拽排序有插入位置指示线；跨分类拖拽时目标分类高亮。
4. 舞台模式的「举手」按钮醒目置于底部操作条中央（对标 Discord Stage「Request to Speak」）。
5. 自动禁说横幅使用警告黄，与人工禁言（红）区分。
6. 频道设置删除项置于左侧导航底部红色区域。
7. 空频道列表（新服）显示引导卡片：「创建你的第一个频道」。

## 6. 边界与异常情况

| 场景 | 客户端行为 |
|------|-----------|
| 点击已满语音频道（≥硬上限 200） | 提示「频道已满」（06 §1.2 超硬顶拒绝进入） |
| 正在语音中频道被删除 | 收到关闭/事件后断开媒体，toast「频道已被删除」，回到频道列表 |
| 正在语音中失去 `CONNECT`（角色变更/Restriction） | 服务端吊销会话（`SESSION_REVOKED` 关闭码）→ 客户端退出房间并说明原因 |
| SFU `closed` 各关闭码 | `TOKEN_EXPIRED`→静默刷新重连；`WRONG_NODE/ROOM_MISMATCH`→重新 `/voice/join`；`NODE_DRAINING`→等待 `VOICE_SERVER_UPDATE` 迁移；`SESSION_REVOKED/CAP_DENIED`→退出并提示（出处：协议 README §2.4） |
| 节点故障热迁移 | 自动接入新节点，短暂静音可接受，全程无需用户操作（07 专项 1） |
| 断网重连 | Gateway resume；语音按最近一次 `VOICE_SERVER_UPDATE` 状态机重入 |
| 拖拽排序提交失败 | 本地回滚到服务端顺序并 toast |
| 频道名/topic 超长 | 本地限长（名称 1–100、topic 1024）先行拦截 |
| 被「禁听」Restriction（语音） | 不可 `CONNECT` 或进房被限制订阅（以服务端实现为准，语义「不能听」，06 §6.1）；客户端显示禁听提示与到期时间 |
| 收到未知频道类型 | 只读降级渲染，不崩溃 |
| 分类被删除 | 其下频道按服务端结果上浮为未分类（对标 Discord） |

## 7. 验收标准

1. 无 `VIEW_CHANNEL` 的成员列表中完全看不到该频道；直接构造 API 请求得到 404；恢复权限后频道在事件/重拉后出现。
2. 管理员创建私密频道并仅勾选角色 X：角色 X 成员可见，其他成员不可见且无任何通知。
3. 拖拽 3 个频道跨分类重排，刷新客户端后顺序与拖拽结果一致。
4. 单击语音频道 2s 内完成进房（局域网环境），房内其他成员的头像与说话绿圈实时出现。
5. 有 `CONNECT` 无 `SPEAK` 的用户进房后麦克风按钮灰置，SFU 侧无 `publish_audio` cap。
6. 管理员在成员说话时对其禁言：1s 内该成员上行停止（对齐控制通道 P99 < 1s），其客户端收到 `caps_updated` 并强制闭麦。
7. 舞台频道：听众举手进入队列，协管抱上后听众变发言者可说话；抱下后立即失去发言能力。
8. 自由讨论频道进入第 51 人：该用户可听不可说并看到自动禁说提示；第 1 位成员退出后该用户自动恢复并收到 toast。
9. 关闭频道入场语音包开关后，新成员进房不再触发音效；打开后恢复。
10. 模拟节点 Drain：房内用户在秒级内自动迁到新节点，期间最多短暂静音，无任何「重新进房」弹窗。

## 9. 关键时序（参考实现）

### 9.1 进入语音频道（对齐 06 §9 与协议 README §2.3）

```text
单击语音频道（校验本地 VIEW_CHANNEL+CONNECT，仅用于 UI 预判）
→ 对候选节点 GET /rtt 并发探测（若服务端要求）
→ POST /voice/join { channel_id, rtt_results }
   ├─ 200 → { media_token, node_endpoint, caps, room_id }
   │    → WSS 连接 node → auth 帧（5s 内首帧）→ ready（房间快照）
   │    → 客户端 offer（上行音频）→ SFU answer → trickle ICE → 媒体连通
   │    → UI：语音卡片出现、频道下成员列表就位
   ├─ 404 → 按「频道不存在」处理（可能被禁看，06 §8）
   └─ 4xx(满员/禁听等) → 对应文案
后续：token 到期前 POST /voice/refresh-token → 新 token 经 auth 帧在位更新
```

### 9.2 热迁移（客户端视角，07 专项 1）

```text
收到 VOICE_SERVER_UPDATE { new_node, new_token, migration_id }
→ 保持旧连接的同时向新节点建立 WSS+WebRTC（make-before-break 尽力）
→ 新节点媒体连通 → 关闭旧连接 → 上报迁移完成
全程 UI 仅显示「正在切换线路…」，禁止任何需用户操作的弹窗
（若旧节点已死：直接重建，允许短暂静音）
```

## 10. 非功能需求

| 指标 | 要求 |
|------|------|
| 点击到听见声音（局域网） | ≤ 2s |
| 说话指示延迟 | ≤ 250ms（对齐 speaking 节流） |
| 热迁移静音时长 | 秒级内自动恢复（07 §1.1 SLA 方向），客户端不额外引入等待 |
| 频道列表渲染（500 频道） | 虚拟滚动，切服 ≤ 300ms 首屏 |
| 入场语音包音频 | 预下载缓存，播放延迟 ≤ 500ms，失败静默丢弃 |
