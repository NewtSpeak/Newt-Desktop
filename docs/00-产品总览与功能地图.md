## 1. 产品定位

Owl-Desktop 是 OwlSpeak 的桌面客户端（macOS / Windows / Linux），提供对标 Discord / KOOK 的完整社区协作体验：

- 用户可创建/加入多个互相独立的 **服务器（Guild）**；
- 每个服务器下有 **文本频道** 与 **语音频道**（可扩展公告/舞台频道）；
- 服务器级与频道级 **完整 RBAC 权限控制**（角色 + 频道覆盖 Overwrite）；
- 语音走 **WebRTC + SFU**，客户端与 SFU 直连，支持多节点级联与 **热迁移**（绝不允许「掉线回大厅手动重进」）；
- 大房间强制 **舞台模式**（台上/听众/麦序/抱麦）；
- **屏幕共享**（SFU 中转、动态配额）；
- **全系统消息搜索**、附件、编辑历史、多维 Restriction 限制体系；
- **入场语音包**（客户端本地播放短音频）。

## 2. 系统边界

```
┌─────────────┐   REST API + Gateway WS（事件）    ┌─────────────┐
│ Owl-Desktop │ ─────────────────────────────────► │ Owl-Server  │  控制面
│  （本项目） │                                    └──────┬──────┘
│             │   WSS 信令 + WebRTC 媒体（UDP/ICE）       │ 控制通道（mTLS）
│             │ ─────────────────────────────────► ┌─────▼──────┐
└─────────────┘                                    │  Owl-SFU   │  媒体面（多节点/级联/热迁移）
                                                   └────────────┘
```

- 业务权限唯一权威在 **Owl-Server**；客户端本地权限计算仅用于 UI 即时反馈，最终以服务端裁决为准。
- 媒体（音频、屏幕流）**不经 Owl-Server 中转**，客户端与被调度到的 SFU 节点直连；TURN 仅作 NAT 兜底。
- SFU 只认 Server 签发的短时 **Media Token**（Ed25519 JWT，TTL 2–5 分钟，caps 最小能力集）。

## 4. 来自服务端定稿的关键硬约束（客户端必须遵守）

以下约束摘自服务端定稿文档（括号内为出处编号），客户端任何设计不得违反：

1. **单语音频道软上限 50 / 硬上限 200**；超硬顶拒绝进入（06 §1.2）。
2. **大房强制舞台模式**：台上软限 20 / 硬顶 50；未合规时第 51 人起按进房序自动禁说（来源 `CAPACITY_QUEUE`），有人离开按序解除（07 专项 3）。
3. **热迁移**：不允许「掉线回大厅/手动重进」；允许短暂静音的自动换节点，秒级恢复（07 专项 1）。
4. **无权限频道 API 一律 404** 且 Gateway 不推送（防扫频，06 议题 8）；客户端将其视为「频道不存在」。
5. **`ADMINISTRATOR` 无视频道 deny**；系统管理员 > 服务器管理员 > 频道协管三级权威（06 议题 4/7）。
6. **Restriction 只收紧**，优先于 RBAC 允许位；四维（文字看/说、语音听/讲）×（单频道/全服）；当事人可见原因+到期时间，他人仅见「被限制」（07 专项 4，12）。
7. **进房主路径 `POST /voice/join`**，辅助 `VOICE_SERVER_UPDATE`；Media Token TTL 2–5 分钟，刷新经 `POST /voice/refresh-token` + `auth` 帧在位重发（06 议题 10，协议 §1）。
8. **WSS 信令**：连接后 5s 内必须发 `auth` 首帧（token 不放 URL）；心跳 `ping` 建议 15s；静音他人 = `unsubscribe` 真实停转发（协议 §2）。
9. **附件**：任意类型可传，仅 PDF/音频/视频/图片内嵌预览；单文件上限由系统管按服务器配置（07 专项 5B）。
10. **消息编辑**：UI 显示「已编辑 + 编辑次数」，编辑历史服务端审计、次数以服务端为准（07 5B.4）。
11. **全系统搜索**：跨服全局检索，但只能命中调用者可见内容，权限过滤在服务端检索层强制（07 5B.5）。
12. **屏幕共享**：SFU 中转（非 Server 中转、非 Mesh）；舞台/大房仅台上可共享；每服并发路数由系统管动态配额（07 专项 5C，14）。
13. **入场语音包**：客户端拉短音频 URL 本地播放，不经 SFU 长轨道；频道级开关；默认同语音频道可听（07 专项 5A）。
14. **服级节点池**：服管只能从系统管授权候选中勾选本服节点池；调度禁止出池（07 专项 2）。
15. **首期范围**：账号 + 服务器/频道骨架 + 语音（含舞台/麦序）+ 文字频道 + RBAC；屏幕共享架构预留、后期必做（06 议题 3/11）。

## 5. 客户端整体信息架构（对标 Discord 布局）

```
┌──┬──────────┬───────────────────────────────┬──────────┐
│服│ 频道列表  │           主内容区             │ 成员列表  │
│务│ (分类/文 │  文本频道：消息流 + 输入框       │ (按角色  │
│器│  本/语音)│  语音频道：参与者格 + 控制条     │  分组)   │
│栏│          │                               │          │
│  │ 用户语音 │                               │          │
│  │ 状态面板 │                               │          │
└──┴──────────┴───────────────────────────────┴──────────┘
  顶部：频道名 / topic / 搜索框（Ctrl/Cmd+K 全局搜索）
  底部左：用户头像 / 静音 / 闭麦 / 设置
```

- 左侧最外层为 **服务器栏**（Discord 风格圆形图标，未读白条、@ 红点角标）。
- 频道列表支持分类折叠、语音频道内联显示当前参与者头像（对标 Discord）。
- 进入语音后底部常驻 **语音状态面板**（连接质量、频道名、断开/静音/闭麦/屏幕共享按钮）。

## 6. 里程碑建议（与服务端 M0–M5 对齐）

| 里程碑 | 客户端范围 |
|--------|-----------|
| C0 | 登录 + 服务器/频道骨架 + Gateway 事件 + 文本收发 |
| C1 | 语音进房（单节点）：join → token → WSS → WebRTC 连通、静音/闭麦、speaking |
| C2 | RBAC 完整 UI（角色/覆盖）+ Restriction 呈现 + 附件与预览 |
| C3 | 热迁移客户端配合（VOICE_SERVER_UPDATE 换节点）+ 关闭码全处理 |
| C4 | 舞台模式 + 麦序/抱麦 + 自动禁说呈现 |
| C5 | 屏幕共享 + 全系统搜索 + 入场语音包 + 通知/设置完备 |
