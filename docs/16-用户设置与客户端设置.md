## 1. 功能概述

本文档定义 Owl-Desktop 的设置体系，覆盖账号类设置（跨端同步）与客户端本地设置（仅本机）。交互整体对标 Discord：齿轮入口打开**全屏设置面板**，左侧分栏导航，`Esc` 关闭；变更即时生效免「保存」按钮（个别危险项除外）。

设置面板一级结构（对标 Discord 用户设置分栏）：

| 分组 | 分栏 | 同步范围 |
|------|------|----------|
| 用户设置 | 我的账号、隐私与安全 | 账号（服务端同步） |
| 应用设置 | 语音与视频、通知、外观、快捷键、语言与区域、Windows/macOS 桌面行为、键盘可访问性 | 通知偏好为账号同步（文档 15 FR-11）；其余默认本机，标注可同步项 |
| 高级 | 本地数据与缓存、日志与诊断、关于 | 本机 |

## 3. 功能需求明细（FR）

### 3.1 面板框架

- **FR-01** 齿轮按钮（用户状态卡片右侧）与快捷键 `Ctrl/⌘+,` 打开设置；全屏覆盖层 + 左侧导航 + `Esc` 关闭（对标 Discord）。
- **FR-02** 除明确标注外，所有设置修改即时生效并持久化；账号类设置写服务端（API 见 §7-1），本机类写本地配置文件。
- **FR-03** 设置项支持搜索过滤（导航顶部搜索框，对标 Discord 设置搜索）。

### 3.2 我的账号 / 隐私与安全

- **FR-04** 我的账号：头像、用户名/昵称、邮箱（脱敏显示）、修改密码、登出、账号删除入口（危险区红色，二次确认）。字段与能力以服务端账号体系为准（§7-2）。
- **FR-05** 隐私与安全：私信/好友类隐私项预留（服务端未定义，§7-2）；已登录设备/会话管理列表（可远程登出，§7-2）。

### 3.3 语音与视频

**设备：**

- **FR-06** 输入/输出设备下拉框，实时枚举系统音频设备；设备热插拔即时刷新；被拔出的当前设备自动回退系统默认并提示。按设备 ID 记忆选择。
- **FR-07** 输入音量、输出音量独立滑杆（0–200%，默认 100%）；输入电平实时可视化；「麦克风测试」回环试音（对标 Discord Let's Check）。

**激活方式：**

- **FR-08** 语音激活（VAD）/ 按键说话（Push-to-Talk）二选一（对标 Discord Input Mode）：
  - VAD：灵敏度滑杆 + 「自动确定输入灵敏度」开关（对标 Discord 自动灵敏度）；电平条以两色显示阈值上下。
  - PTT：快捷键绑定（支持键盘+鼠标侧键组合）、释放延迟滑杆（0–2000ms，对标 Discord PTT Release Delay）、全局生效需系统辅助功能/输入监控权限，设置页内提供权限状态与引导。
- **FR-09** 本地静音/闭麦逻辑：UI 静音按钮 = `self_mute`，闭听按钮 = `self_deaf`，经 `PATCH VoiceState` 上报并广播（Server-05 §9）；本地立即停采/停放为主，服务端为双保险。恢复说话需 `self_mute=false` 且 `server_mute=false` 且具备 `SPEAK`（Server-05 §9），设置页帮助文案需解释该关系。

**音频处理（端侧）：**

- **FR-10** 回声消除（AEC）、噪声抑制（NS，可选基础/强档如 RNNoise 类）、自动增益（AGC）三项独立开关，默认全开（对标 Discord/KOOK 默认）；修改即时应用于当前会话（重建本地音频处理链，不重建 PC）。
- **FR-11** 抗丢包为端侧职责（SFU 纯转发不做 jitter buffer，Server-15 §7.1「音频策略」）：客户端必须启用 Opus in-band FEC 与本地 jitter buffer；高级区提供「网络抗性优先/延迟优先」档位（默认自动）。
- **FR-12** 每用户音量与本地静音：右键房内成员可调其音量（0–200%）与「静音」；**静音某人 = 发送 `unsubscribe` 真实退订**，服务端级联停转发该路（Server-08 D.5、Server-协议 §2.1）；取消静音 = `subscribe` 恢复。该状态本机持久化并在重连后重放（文档 13 FR-21）。

**视频/屏幕共享（预留）：**

- **FR-13** 摄像头设备选择与预览占位；屏幕共享入口受 `STREAM` 权限与服级动态配额约束（Server-07 5C），首期功能未实装时隐藏或置灰并注明。

**连接信息调试面板：**

- **FR-14** 「语音与视频」底部提供调试面板（对标 Discord 语音调试信息），实时显示：当前 SFU 节点（node 域名/`node_id`）、WSS 状态、ICE 状态与候选类型（host/srflx/relay）、当前 RTT（媒体层）与 `GET /rtt` 探测值、上行/下行丢包率、抖动、码率、Opus FEC 状态、当前 `sid`、caps 列表、最近一次迁移的 `migration_id` 与耗时（文档 13 FR-05）。技术字段的展示深度遵循 Server-09 O.2：普通用户可见基础网络质量，节点 ID 等细节默认收起。
- **FR-15** 「重置语音设置」按钮：恢复本分栏全部默认值（二次确认，对标 Discord）。

### 3.4 通知

- **FR-16** 承载文档 15 的全局层设置：全局默认通知级别（全部/仅@提及/无）、系统通知总开关与隐私开关（FR-12/文档 15）、各提示音开关与音量、试听、勿扰行为子项（角标是否保留）、「仅提及显示角标」开关（文档 15 FR-18）。服务器/频道级覆盖入口在各自右键菜单（文档 15 UX-06），本页展示「已覆盖列表」便于统一管理（对标 Discord 通知设置页的服务器覆盖列表）。

### 3.5 外观

- **FR-17** 主题：深色 / 浅色 / 跟随系统（默认跟随系统）；切换即时全局生效，无重启。
- **FR-18** 字体缩放：与 Discord 一致提供离散档（12/14/15/16/18/20/24px，默认 16）+ 整体界面缩放（67%–200%，快捷键 `Ctrl/⌘ +/-/0`）。
- **FR-19** 消息显示密度：舒适（头像+多行留白）/ 紧凑（IRC 式单行，对标 Discord Cozy/Compact）。
- **FR-20** 无障碍相关外观项：减弱动态效果（尊重系统 prefers-reduced-motion 且可手动强制）、饱和度调节、始终显示链接下划线。

### 3.6 快捷键

- **FR-21** 快捷键页列出全部可自定义动作并支持重绑定与冲突检测（同上下文冲突高亮警告）：PTT（说话）、切换静音、切换闭听、切换勿扰、打开设置、服务器/频道快速切换（`Ctrl/⌘+K`，对标 Discord Quick Switcher）、标记服务器已读（`Shift+Esc`）、收件箱、导航前进/后退、界面缩放。
- **FR-22** 快捷键分「应用内」与「全局」两类；全局类（PTT、切换静音/闭听）在失焦时生效，需要系统权限（macOS 输入监控/辅助功能），页面内提供权限检测与引导。
- **FR-23** 提供「恢复默认」与逐条清除绑定。

### 3.7 语言与区域

- **FR-24** 界面语言选择（首期至少：简体中文、English；默认跟随系统）；切换即时生效。语言包机制预留第三方语言扩展。
- **FR-25** 时间显示：12/24 小时制（默认跟随系统区域）；日期格式跟随所选区域；所有时间戳基于服务端 UTC 换算本地时区显示（文档 14 边界表「本地时钟偏差」）。

### 3.8 桌面行为（Windows/macOS）

- **FR-26** 开机自启开关（macOS Login Items / Windows 注册表 Run 键）+「启动时最小化」子开关。
- **FR-27** 关闭按钮行为：最小化到托盘（默认，Windows）/ 退出应用 可选；macOS 遵循平台惯例（关窗不退出，Dock 常驻）。托盘/菜单栏图标提供：打开、静音、闭听、退出。
- **FR-28** 「最小化到托盘时保持语音连接」恒为真（不做成开关）；托盘图标反映语音在线与未读状态（文档 15 FR-19）。

### 3.9 键盘可访问性

- **FR-29** 全界面可 Tab 键盘导航，焦点环清晰可见；消息列表、频道树、成员列表支持方向键导航（对标 Discord 键盘导航模式）。
- **FR-30** 屏幕阅读器支持：关键控件提供无障碍标签；新消息/被提及可选屏幕阅读器播报开关。
- **FR-31** 「按 Tab 后显示键盘导航提示」与快捷键速查表（`Ctrl/⌘+/`，对标 Discord Keybinds 速查）。

### 3.10 本地数据与缓存管理

- **FR-32** 「本地数据」页显示分类占用：消息缓存、图片/附件缓存、语音包音频缓存（Server-07 5A.3 客户端拉短音频本地播放，需缓存）、日志。各类独立「清理」+「全部清理」；清理不得登出账号、不得丢失本机设置。
- **FR-33** 图片/附件缓存设上限（默认 1GB，可调），LRU 淘汰；清理后消息界面按需重新拉取（附件为短时签名 URL，需重新获取，Server-13 AT.7）。
- **FR-34** 提供「打开数据文件夹」入口便于排障。

### 3.11 客户端日志与诊断

- **FR-35（日志）** 客户端持续写滚动日志（默认 INFO，诊断模式 DEBUG；单文件 10MB × 5 轮转）。语音相关必须记录：join/leave、每次 WSS 连接与关闭码（Server-协议 §2.4 全部 8 种）、token 刷新、`VOICE_MIGRATING/SERVER_UPDATE/MIGRATED` 与 `migration_id`、双 PC 各阶段时间戳、ICE 状态迁移、RTT 探测样本与上报、Gateway 断连/resume 结果。日志不得含 token 原文与消息正文（隐私）。
- **FR-36（诊断面板）** 「日志与诊断」页提供：当前语音连接概要（同 FR-14 数据源）、最近 24h 语音事件时间线（迁移、重连、关闭码）、静音窗口时长统计（与 Server-09 §11 指标口径一致，便于与服务端对账）、Gateway 连接历史。
- **FR-37（一键导出）** 「导出诊断包」：打包脱敏日志 + 环境信息（OS 版本、应用版本、设备名单、网络类型）+ 最近语音会话摘要（node_id、sid、migration_id 列表）为 zip，供用户提交工单。可选「上报到服务端」通道见 §7-3。
- **FR-38（实时质量指标采集）** 每语音会话周期采样 WebRTC stats（2s 粒度）：RTT、丢包、抖动、码率、并发下行轨数；本地保留最近会话曲线供诊断面板绘图；作为 Server-09 §11「静音窗口时长」等指标的客户端侧数据源。

## 4. UI/UX 要求

- **UX-01** 设置面板视觉对标 Discord：全屏、左窄导航右宽内容、分组标题大写小字、危险操作红色分区。
- **UX-02** 所有开关即时生效并有 150ms 内的视觉反馈；需要重启的项（理论上应为零）必须内联标注。
- **UX-03** 语音设备下拉在语音会话中切换设备须无缝热切（不掉出频道、重建音频轨不重建会话）。
- **UX-04** 调试面板数据 1s 级刷新；数值异常（丢包 > 5%、RTT > 300ms）以黄色/红色标示并附解释 tooltip。
- **UX-05** 权限引导（麦克风、通知、全局快捷键）统一样式：状态徽章（已授权/未授权）+「前往系统设置」按钮 + 简短说明。
- **UX-06** 键盘录制控件（快捷键绑定）录制态高亮，`Esc` 取消，冲突即时红字提示。
- **UX-07** 清理缓存等耗时操作显示进度与结果摘要（释放了多少空间）。

## 6. 边界与异常情况

| 场景 | 行为 |
|------|------|
| 语音会话中拔掉当前输出设备 | 自动回退系统默认设备，媒体不断；提示条 3s |
| PTT 快捷键与系统/其他应用冲突 | 冲突检测仅覆盖应用内；全局冲突无法枚举，文档说明 + 允许用户自行更换 |
| macOS 未授权麦克风 | 进语音时引导授权；拒绝后进房为「只听」状态并在语音卡片常驻提示 |
| 未授权输入监控（macOS 全局 PTT） | PTT 退化为仅应用内生效，设置页黄色警示 |
| 设置文件损坏 | 启动时校验失败则重置为默认并备份原文件，提示用户 |
| 账号设置同步失败（离线） | 本地先行生效，恢复后台重试上行；冲突以服务端最新为准（文档 14 FR-13 同原则） |
| 清缓存时正在语音 | 允许；跳过正在使用的运行时文件 |
| 诊断模式忘记关闭 | DEBUG 级别 24h 后自动回落 INFO |
| 多显示器 DPI 差异 | 界面缩放按窗口所在显示器 DPI 独立应用 |
| 服务器管理员开启「详细迁移原因」（Server-09 O.2） | 诊断面板与语音卡片 hover 展示技术原因；默认模糊文案不变 |

## 7. 依赖服务端待补充

1. **用户设置同步 API**：通知偏好（文档 15 FR-11）、每服务器/频道覆盖、可同步的应用设置白名单；建议 `GET/PATCH /users/@me/settings`。
2. **账号体系细节**：注册/邮箱/密码/会话设备管理/隐私项，服务端文档未覆盖（当前文档集中在语音与消息域）。
3. **客户端诊断上报通道**：FR-37「上报到服务端」需要上传端点与配额/脱敏约定；同时对齐 Server-15 BI.2 的 ICE 失败上报格式（与文档 13 §7-3 同项）。
4. **`GET /rtt` 响应体格式**：仅约定端点与限速（Server-15 BF.5），响应字段（时间戳回显等）未定义，影响 RTT 计算口径。
5. **每用户音量是否服务端同步**：首期按本机持久化处理，若需跨端同步需新增设置域。
6. **语音包音频 URL 的缓存策略约定**（TTL/签名有效期），影响 FR-32 缓存分类实现。

## 8. 验收标准

| # | 验收项 | 通过条件 |
|---|--------|----------|
| AC-01 | 语音中切换输入/输出设备 | 3s 内生效；不退出频道、PC 不重建 |
| AC-02 | PTT 全流程 | 绑定组合键成功；失焦（已授权）仍可说话；释放延迟符合设定 |
| AC-03 | VAD 灵敏度 | 阈值滑杆与电平条一致；自动模式下环境噪声不触发发言绿圈 |
| AC-04 | AEC/NS/AGC 开关 | 会话中切换即时生效（可用录音对比验证），无重连 |
