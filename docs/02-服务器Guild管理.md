## 1. 功能概述

服务器（Guild）是 OwlSpeak 的独立权限域与社区单元（服务端 01 文档 §4.1：用户可加入多个互相独立的服务器，跨服数据与权限不共享）。本文档定义桌面客户端围绕 Guild 的全部功能：

- **服务器列表侧栏**：应用最左侧竖排图标栏，对标 Discord Server Rail。
- **创建 / 加入 / 退出 / 删除服务器**、**所有权转让**。
- **服务器设置**：名称、图标、横幅等基础资料。
- **邀请系统**：邀请链接生成（`CREATE_INSTANT_INVITE` 权限位）、过期时间与使用次数限制。
- **服务器发现**：公开服务器浏览与搜索（对标 KOOK 发现页 / Discord Server Discovery）。
- **成员列表**：右侧成员面板，按角色分组。
- **服级节点池配置入口**：服务器管理员仅能从系统管理员授权的候选 SFU 节点中勾选本服节点池（服务端 07 文档 专项 2 §2.1）。

服务端现状：swagger v0.1.0 仅有 `GET/POST /guilds`（列表与创建，创建仅 `name` 字段）；其余接口标注「需服务端补充 API」，汇总见 §8。

## 3. 功能需求明细（FR）

### 3.1 服务器列表侧栏（Server Rail）

- **FR-01 布局**：应用最左侧固定竖栏（宽约 72px），从上到下：私信/主页入口 → 分隔线 → 已加入服务器圆形图标（可拖拽排序，顺序存本地+云端同步 P1）→「+」创建/加入 → 指南针「发现」入口。严格对标 Discord 服务器栏。
- **FR-02 图标呈现**：有图标显示图片，无图标显示名称首字母缩写（≤4 字符）；悬停时圆形→圆角方形过渡动画 + 名称 tooltip（Discord 交互惯例）。
- **FR-03 状态徽标**：图标左侧白色胶囊指示：当前选中（长条）、有未读（短点）、悬停（中条）；@提及数以红色数字徽标叠加在图标右下。
- **FR-04 数据源**：登录后调用 `GET /guilds` 渲染列表；后续通过 Gateway `GUILD_CREATE` / `GUILD_UPDATE` / `GUILD_DELETE` 事件增量维护（事件命名沿用 Discord 惯例，待服务端 Gateway 协议定稿）。

### 3.2 创建服务器

- **FR-05 创建入口**：点「+」弹窗，两个选项：「创建服务器」与「加入服务器」（对标 Discord Add a Server 弹窗）。
- **FR-06 创建表单**：名称（2–100 字符，与 `createGuildRequest` 一致）必填；图标可选（创建后上传，因当前 API 仅收 name）。调用 `POST /guilds` → 201 后侧栏即时插入并自动切换到新服。
- **FR-07 初始结构**：创建成功后客户端期望服务端已初始化：所有者成员、`@everyone` 角色（position=0，默认可看/发/连麦/说话，出处：02 §3.3、06 §7.2）与默认频道；若服务端未建默认频道，客户端引导所有者创建第一个文本/语音频道。

### 3.3 加入 / 退出服务器

- **FR-08 邀请解析**：「加入服务器」输入框接受完整 URL 或纯邀请码；调用邀请预览接口显示服务器名、图标、在线/总成员数，确认后加入。〔需服务端补充 API：`GET /invites/:code`、`POST /invites/:code/join`〕
- **FR-09 无效邀请**：过期/超次/已撤销的邀请显示「邀请已失效」，不泄露服务器信息。
- **FR-10 退出服务器**：服务器名下拉菜单「退出服务器」，红色危险项 + 二次确认弹窗（需输入服务器名确认为 P1，首期普通确认即可）。所有者不可直接退出，提示先转让所有权或删除服务器（对标 Discord）。
- **FR-11 被踢/被封禁**：收到 Gateway 成员移除事件后，侧栏移除该服；若用户正停留在该服界面，跳转回主页并 toast 说明。被 Ban 后使用邀请码重新加入应得到明确失败提示（`Ban Member` 语义出处：07 专项 4 §4.5——全服踢出用 Ban，不与 Restriction 混用）。

### 3.4 服务器设置（概览）

- **FR-12 设置入口**：频道列表顶部服务器名下拉菜单 →「服务器设置」，进入全屏设置页（对标 Discord Server Settings），左侧导航：概览 / 角色（见 04 文档）/ 频道（见 03 文档）/ 成员 / 封禁 / 邀请 / 语音节点 / 审计日志（P1）。
- **FR-13 概览页**：可编辑名称、图标（512×512 建议，≤8MB）、横幅（960×540 建议，P1）、服务器简介；仅 `MANAGE_GUILD` 权限位（bit 5，出处：02 §3.2）持有者可见可编辑，否则整个设置入口按 04 文档灰置规则处理。〔需服务端补充 API：`PATCH /guilds/:id` 及图标/横幅上传〕
- **FR-14 保存条**：设置页有未保存修改时底部浮出「有未保存的更改」提示条（保存/重置），对标 Discord 设置保存条。

### 3.5 邀请系统

- **FR-15 生成邀请**：频道右键或服务器菜单「邀请其他人」弹窗：展示当前邀请链接 + 复制按钮；「编辑邀请链接」可配置——过期时间（30 分钟 / 1 小时 / 6 小时 / 12 小时 / 1 天 / 7 天 / 永不）与最大使用次数（无限制 / 1 / 5 / 10 / 25 / 50 / 100），完全对标 Discord 邀请配置项。
- **FR-16 权限门槛**：仅当用户对该频道/服务器最终权限含 `CREATE_INSTANT_INVITE`（bit 0，出处：02 §3.2）时展示邀请入口，否则隐藏。
- **FR-17 邀请管理页**：服务器设置「邀请」页列出活跃邀请（码、创建者、已用/上限、过期时间），有管理权限者可撤销。〔需服务端补充 API：邀请 CRUD〕
- **FR-18 邀请指向**：邀请可绑定默认落地频道（生成自哪个频道），加入后自动定位该频道。

### 3.6 服务器发现

- **FR-19 发现页**：侧栏指南针进入全屏发现页：搜索框 + 分类标签（游戏/学习/科技/音乐等）+ 服务器卡片（横幅、图标、名称、简介、在线/成员数），对标 KOOK 发现页与 Discord Server Discovery。
- **FR-20 加入即预览**：从发现页点进服务器直接加入（公开服）；P1 支持 Discord 式「预览模式」（Lurker）。
- **FR-21 公开性设置**：服务器设置提供「加入方式」：仅邀请（默认）/ 公开可发现。〔需服务端补充 API：发现列表、公开性字段；整个发现功能可整体列为 P1〕

### 3.7 成员列表与成员管理

- **FR-22 成员面板**：频道界面右侧可折叠成员列表：按「可分组显示（hoist）的角色」分组，组内按在线状态与名称排序，离线成员统一沉底为「离线」组（对标 Discord；hoist 字段出处：02 §2 角色概念）。
- **FR-23 成员右键菜单**：资料卡、@提及、修改昵称（`MANAGE_NICKNAMES`）、身份组分配（见 04 文档）、移出语音/静音（见 03 文档）、踢出（`KICK_MEMBERS`）、封禁（`BAN_MEMBERS`）、施加限制（Restriction，见 04 文档）。所有管理项按 04 文档的权限与层级规则动态显示/灰置。
- **FR-24 成员设置页**：服务器设置「成员」页支持搜索、按角色筛选、批量查看加入时间；「封禁」页列出封禁记录并支持解封（`BAN_MEMBERS`）。〔需服务端补充 API：成员列表分页、kick/ban/unban〕
- **FR-25 大服务器优化**：成员列表使用虚拟滚动 + 分页拉取（Gateway 按需请求成员分片，对标 Discord Lazy Guild / `REQUEST_GUILD_MEMBERS`）。

### 3.8 所有权与删除

- **FR-26 转让所有权**：所有者可在成员管理中「转让所有权」，需二次确认 + 输入密码；转让后自己保留原角色。所有者隐式拥有全部权限且不受层级限制（出处：02 §3.3、§4）。〔需服务端补充 API〕
- **FR-27 删除服务器**：仅所有者可删；确认弹窗需手动输入服务器名称（对标 Discord 删除确认）；删除后所有成员的侧栏经 Gateway 事件移除该服。〔需服务端补充 API：`DELETE /guilds/:id`〕

### 3.9 服级节点池配置（语音节点）

依据 07 专项 2 定稿：

- **FR-28 入口与权限**：服务器设置「语音节点」页，仅服务器管理员（`ADMINISTRATOR`/所有者，或被授予对应权限节点者）可见；系统管理员可见任意服的该页。
- **FR-29 候选集勾选**：页面列出**系统管理员授权给本服的候选节点**（名称、region 标签、合规标签、容量档、在线状态），服务器管理员以复选框勾选组成本服节点池；**不可添加候选集之外的任何节点**（07 §2.1：服管仅能从被授权候选中勾选，不能把流量指到未审核机器）。
- **FR-30 空池回落提示**：未勾选任何节点时显示提示：「未配置节点池，将回落到平台默认池」；若系统管理员已关闭本服回落开关，则显示红色警告「无可用节点，语音功能不可用」（出处：07 §2.2）。
- **FR-31 多 region 提示**：允许勾选多个 region 的节点并提示「跨区节点可让不同地域成员就近接入」（出处：07 §2.5）；合规标签受限的节点显示锁标并说明原因（07 专项 2 注意 1）。
- **FR-32 池变更影响提示**：移除正在承载语音的节点时，提示「该节点上的语音用户将被自动热迁移到池内其他节点」（出处：07 §2.4 注意 2：池变更删节点 → Drain/热迁移）。
- **FR-33 系统管平台入口**：`system_admin = true` 的用户在客户端拥有独立「平台管理」入口，可管理节点定义、标签、授权矩阵（哪些节点可被哪些服选）、每服屏幕共享配额（07 5C.3b）、每服附件大小上限（07 5B.3b）、服级回落开关。该入口的详细规格另立文档，本文仅要求入口与导航占位。
- **FR-34 节点池 API**：〔需服务端补充 API：`GET /guilds/:id/voice-nodes/candidates`、`PUT /guilds/:id/voice-nodes/pool` 及系统管授权接口；07 已定产品语义，接口未落 swagger〕

## 4. UI / UX 要求

1. 侧栏、设置页、弹窗交互全部对标 Discord：ESC 关闭全屏设置、危险操作红色按钮、破坏性操作需输入名称确认。
2. 服务器图标上传复用 01 文档 FR-16 的裁剪器；横幅按 16:9 裁剪。
3. 邀请弹窗内链接一键复制后按钮变绿显示「已复制」2 秒（Discord 惯例）。
4. 成员列表虚拟滚动在 5000+ 成员时保持 60fps。
5. 节点池页每个节点卡片显示：在线状态点、region 旗帜/标签、当前负载条（若服务端提供）、合规锁标。
6. 所有管理入口遵循 04 文档「无权限即隐藏或灰置」的统一规则：整页无权限则导航项隐藏；页内个别操作无权限则灰置 + tooltip 说明缺失权限。

## 6. 边界与异常情况

| 场景 | 客户端行为 |
|------|-----------|
| 创建服务器 name 不合法 | 本地校验 2–100 字符，服务端 400 时字段级提示 |
| 邀请码失效/超次 | 「邀请已失效」页，不显示任何服务器信息 |
| 加入已在其中的服务器 | 直接跳转该服，不重复加入 |
| 被封禁后用新邀请加入 | 明确提示被封禁（文案不含封禁原因，除非服务端下发） |
| 所有者尝试退出 | 拦截并弹窗引导「转让所有权」或「删除服务器」 |
| 删除服务器时输入名称不匹配 | 确认按钮保持禁用 |
| 节点池候选为空（系统管未授权） | 页面显示「请联系平台管理员为本服授权语音节点」 |
| 勾选的节点全部离线 | 警告条提示语音可能不可用；是否回落由服务端策略决定（07 §2.2） |
| 正在语音时本服节点池被修改 | 客户端按热迁移流程处理（收到 `VOICE_SERVER_UPDATE` 换节点，允许短暂静音，禁止回大厅，出处：07 专项 1 §1.1） |
| Gateway 断连期间错过成员/服务器事件 | 重连后全量重拉 `GET /guilds` 与当前服快照做差量修正 |
| 同时在两端退出/加入服务器 | 以 Gateway 事件为准收敛最终状态 |

## 7. 验收标准

1. 新用户创建服务器后，侧栏立即出现新图标并自动进入；重启客户端后 `GET /guilds` 仍能列出。
2. A 生成「1 天 / 10 次」邀请链接，B 粘贴后能看到预览并加入；第 11 个用户使用同链接得到失效提示。
3. 无 `CREATE_INSTANT_INVITE` 的成员在该频道看不到任何邀请入口。
4. 无 `MANAGE_GUILD` 的成员打开服务器菜单看不到「服务器设置」中的概览编辑项。
5. 所有者点击退出被拦截；转让所有权后可正常退出；删除服务器需输入全名，删除后其他在线成员侧栏 2s 内移除该服。
6. 服务器管理员在节点池页只能看到被授权候选节点；接口层面尝试提交候选外节点 ID 时被服务端拒绝且客户端给出错误提示。
7. 空节点池 + 回落开启：语音可用；空池 + 回落关闭：进语音得到明确失败文案（对齐 07 §2.2）。
8. 被踢出服务器的成员客户端在 2s 内移除该服并跳转主页。
9. 成员列表 5000 成员滚动无卡顿，离线成员正确沉底分组。

## 9. 关键时序（参考实现）

### 9.1 通过邀请加入服务器

```text
用户粘贴链接/邀请码 → GET /invites/:code
  ├─ 200 → 展示预览（名称/图标/成员数）→ 用户确认 → POST /invites/:code/join
  │        ├─ 200 → Gateway 收到 GUILD_CREATE（本人视角）→ 侧栏插入 → 跳转落地频道
  │        ├─ 403(被封禁) → 「你已被该服务器封禁」
  │        └─ 410/404(失效) → 「邀请已失效」
  └─ 404 → 「邀请已失效」（不泄露服务器存在性）
```

### 9.2 服管配置节点池

```text
打开设置「语音节点」→ GET /guilds/:id/voice-nodes/candidates（系统管授权候选）
→ 勾选/取消勾选 → 底部保存条 → PUT /guilds/:id/voice-nodes/pool
  ├─ 200 → toast 成功；若删除了承载中节点 → 服务端触发 Drain/热迁移（07 §2.4）
  └─ 400(含候选外节点) → 整体回滚 + 错误提示
```

## 10. 非功能需求

| 指标 | 要求 |
|------|------|
| 侧栏首屏渲染（50 个服务器） | ≤ 500ms（登录后） |
| 邀请预览接口反馈 | ≤ 1s 内显示预览或失效态 |
| 成员列表滚动 | 5000 成员虚拟滚动 60fps |
| Gateway 服务器事件应用延迟 | 收到事件到 UI 更新 ≤ 300ms |
| 图标/横幅上传 | 客户端压缩至上限内再上传；失败可重试 |

## 11. 术语表
